# Implementation Plans

This directory contains the v1 product specification, the original implementation strategy,
implementation plans, and future candidates. It is implementation history, not the home of current
domain language or durable technical decisions.

- `packref-v1-spec.md` is the authoritative v1 behavior contract.
- `implementation-strategy.md` records the strategy used to build v1 and may contain historical
  sequencing notes.
- Numbered plans `02` through `09` record implementation slices.
- `v2-features.md` collects non-v1 candidates.

For current contributor guidance, read [`CONTEXT.md`](../CONTEXT.md),
[`docs/architecture.md`](../docs/architecture.md), and the
[`docs/adr/`](../docs/adr/README.md) index.
